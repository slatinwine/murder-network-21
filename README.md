# 21世纪杀人网络（Murder Network in the 21st Century）

一款 AI 主理人主持的公平本格推理文字冒险游戏：AI 时代九成悬案都被算法破解，剩下的「算法与网络双重失效」案件，将转单送到你——二十一世纪最后的名侦探桌上。

## ✨ 功能特性

- 随机抽卡生成案件：诡计（源自江户川乱步《诡计集成》分类）× 七宗罪动机 × 舞台 × 被害人，每局全新
- AI 主理人演出一切：安乐椅派 AI 助手转单开场、案发现场、嫌疑人与证词均由大模型扮演
- 五类侦探指令：【搜查】【问询】【呼叫助手】做数据比对、【思考】整理推理、【最终推理】指认凶手
- 公平本格承诺：所有破案必需线索都会在揭晓前出现（FAIR-PLAY MYSTERY）
- 结算评分 S/A/B/C，逐项判定凶手、手法、动机，并揭晓完整真相与守则吐槽
- 进度自动存档（localStorage），支持「继续上局」与随时「换一案」

## 🚀 使用方法

1. 用浏览器直接打开 `index.html`（需联网访问云端 AI 服务与访客统计）
2. 点击「开始游戏」抽取案件，用底部指令按钮或自由输入展开调查
3. 想自己主持一局？阅读 `GM-主理人手册.md`，按核心循环手动主持即可

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript 单文件应用
- WorkBuddyCloud LLM 流式对话接口（温度 0.9）驱动主理人
- localStorage 存档 / IP 登记 / hits.sh 访客徽章
